Nesta seção, apresentamos e discutimos os resultados obtidos com a aplicação dos quatro algoritmos de agrupamento (KMeans, Fuzzy C-Means, Gustafson-Kessel e Agglomerativo) nos conjuntos de dados Adult e Dry Bean. São analisadas as métricas quantitativas, as visualizações e as principais observações para cada cenário, destacando as vantagens, limitações e particularidades de cada abordagem em contextos binário e multiclasse.

\textbf{Fluxo do Setup de Teste:}

O processo experimental seguiu a seguinte sequência para ambos os conjuntos de dados:
\begin{enumerate}
    \item \textbf{Pré-processamento:} Codificação numérica das variáveis categóricas (quando presentes) e normalização dos atributos.
    \item \textbf{Balanceamento:} Aplicação de oversampling para igualar a quantidade de exemplos em cada classe (tanto no Adult quanto no Dry Bean).
    \item \textbf{Divisão dos dados:} Separação estratificada em 70\% para treinamento e 30\% para teste.
    \item \textbf{Seleção do número de clusters:} Definição do número de clusters com base no método do cotovelo (Adult: 2; Dry Bean: 7).
    \item \textbf{Execuções:} Realização de 30 repetições com diferentes sementes para garantir robustez estatística dos resultados.
    \item \textbf{Parâmetros do algoritmo:} (Descrever os parâmetros específicos de cada algoritmo, como grau de fuzzificação para Fuzzy C-Means, matriz de covariância para Gustafson-Kessel, etc.)
\end{enumerate}

\subsection{Bases de Dados e Pré-processamento}


Neste trabalho, utilizamos os conjuntos de dados \textbf{Adult} (Census Income) e \textbf{Dry Bean}, ambos amplamente empregados em tarefas de classificação e agrupamento. Para garantir a comparabilidade entre os métodos, ambos passaram por um pré-processamento padronizado: todas as variáveis categóricas foram transformadas em representações numéricas, os atributos foram normalizados e os dados foram divididos de forma estratificada em 70\% para treinamento e 30\% para teste. Além disso, em ambos os conjuntos foi aplicado balanceamento por oversampling, igualando a quantidade de exemplos em cada classe antes da divisão em treino e teste. Essa etapa foi fundamental para evitar viés nos resultados e garantir que os métodos de agrupamento pudessem explorar de forma justa as relações entre as amostras e as classes reais.

\subsection{Seleção do Número de Clusters: Método do Cotovelo}

Para definir o número ideal de clusters ($k$) nos experimentos de agrupamento, utilizamos o \textbf{método do cotovelo} aplicado aos dados balanceados e normalizados de cada base. O procedimento foi implementado nos notebooks específicos para cada conjunto:

\begin{itemize}
    \item \textbf{Adult:} O notebook executa o KMeans para $k$ variando de 2 a 24, calculando a soma das distâncias quadráticas (inertia) para cada valor. O gráfico gerado (Figura~\ref{fig:elbow_adult}) mostra uma queda acentuada até $k=2$, indicando o "cotovelo" e sugerindo que dois clusters são suficientes para capturar a estrutura principal dos dados, o que coincide com o número de classes reais (<=50K e >50K).
    \item \textbf{Dry Bean:} Da mesma forma, o método do cotovelo foi aplicado ao dataset balanceado, variando $k$ de 2 a 24. O gráfico correspondente (Figura~\ref{fig:elbow_drybean}) mostra o cotovelo em $k=7$, alinhado ao número de cultivares presentes no conjunto. Isso indica que sete clusters são ideais para representar a diversidade das classes reais.
\end{itemize}

Em ambos os casos, o método do cotovelo foi fundamental para fundamentar a escolha do número de clusters nos experimentos, garantindo que a avaliação dos algoritmos de agrupamento fosse realizada de forma justa e alinhada à estrutura dos dados. \textbf{Discussão:} Os resultados mostram que o KMeans supervisionado, mesmo sendo um método originalmente não supervisionado, pode atingir desempenho competitivo em tarefas de classificação quando aliado a uma estratégia de rotulação dos clusters. O balanceamento das classes foi fundamental para evitar viés para as classes majoritárias, especialmente no dataset Adult. O desempenho no Dry Bean foi superior, refletindo a maior separabilidade das classes neste conjunto. Todos os resultados quantitativos e gráficos foram salvos em arquivos para reprodutibilidade e análise posterior.
